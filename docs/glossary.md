# Terminology Specification

This specification standardizes terminology across the entire HNS framework
and serves as the Vocabulary Specification for HNS 1.0.

## 1. Volume Layer
In the six volumes, “Layer” refers to the publishing hierarchy.
This is distinct from the Natural Layers defined here.

## 2. Human Natural Layers (Causal Structure)
The six causal strata that constitute the natural structure of humans, societies, and civilizations.

• Layer 1 — PhysicalOS  
Physical and biological foundations.

• Layer 2 — CognitiveOS  
Perception, memory, processing, internal cognition.

• Layer 3 — InteractionOS  
Human‑to‑human and human‑to‑environment interactions.

• Layer 4 — EnvironmentOS  
Physical, social, and institutional environments.

• Layer 5 — LoadOS  
Internal and external loads, pressures, constraints.

• Layer 6 — PatternOS  
Behavioral patterns and emergent outcomes.

## 3. Abstract Cognitive Categories (Non‑causal Explanatory Axes)
Non‑causal explanatory axes applied across Natural Layers.

• Civilization Categories  
Broad abstractions of civilization.

• Core Categories  
Foundational principles and essential structures.

• Module Categories  
Components, elements, functional units.

• Application Categories  
Practical uses and applied contexts.

• System Categories  
Organized systems and societal mechanisms.

• External Categories  
Extensions and outer contextual factors.

## 4. Module (Internal Module)
Functional internal structures within the Natural Layers.

## 5. System / External Module
External structures interpreted through Categories.

## 6. Terminological Priority
1. Human Natural Layers  
2. Abstract Cognitive Categories  
3. Module  
4. System / External Module
