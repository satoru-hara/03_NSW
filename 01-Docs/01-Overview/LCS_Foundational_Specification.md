This document defines the foundational structure of LCS, including its natural layers, causal hierarchy, and semantic coordinate system.

---

## 1. Purpose

## 2. Natural Layers
LCS consists of six layers:

1. Physical Layer  
2. Biological Layer  
3. Cognitive Layer  
4. Social Layer  
5. Institutional Layer  
6. Civilizational Layer  

Each layer represents a natural causal domain.

## 3. Explanatory Categories

These categories combine with the six layers to form **LCS‑36**.

This is the minimal structural coordinate system for world‑level cognition.
