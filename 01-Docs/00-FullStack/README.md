------------------------------------------------------------
1. Scope
------------------------------------------------------------
This folder (00-FullStack) serves as the official entry point and
top-level integration layer of the EVA-HNS Full-Stack Specification Series.

It defines the meta-architecture, document family, and structural
relationships among:

- HumanOS (Integration Layer)
- HNS-36 (Structural Coordinate System)
- HNS-144 (Observational Operating System)
- HNS-864 (Analytical Operating System)
- EVA (External Verification Architecture)
- Three Rationale Documents (Depth / Category / Architecture)

This folder corresponds to:
"Part 0: Framework" in ISO/IEC multi-part standards.

2. Architecture Overview
------------------------------------------------------------

HumanOS (Integration Layer)
 |

 |
