## Purpose

This repository organizes the Human Natural Structure (HNS) six-part publication series and the associated EVA-HNS demonstration materials.

It is designed for researchers, engineers, reviewers, and standardization stakeholders who need to understand:

- the HNS six-part series,
- the seven PoC demonstrations,
- the supporting overview / validation / glossary documents,
- conformance and benchmark materials,
- external verification and audit-log examples,
- citation and attribution.

The safest demonstrated claim is:

> **EVA-HNS can convert AI-output evaluation into a coordinate-based, externally auditable verification record using HNS structural coordinates, SMS-6 grounding layers, and EVA audit logs.**

This repository does **not** claim formal standards adoption or universal proof of hallucination elimination.
