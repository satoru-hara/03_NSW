# EVA-HNS Risk Register

| Risk | Description | Mitigation |
|---|---|---|
| Framework-internal scoring | Criteria may favor HNS categories. | Use independent reviewers and blind scoring. |
| Single-model limitation | Results may not generalize. | Test multiple model families. |
| Language limitation | Results may differ by language. | Test English, Japanese, and multilingual data. |
| Overclaiming | PoC may be read as proof of elimination. | Clearly state non-claims. |
| Standards misunderstanding | Readers may think EVA-HNS is adopted. | Maintain status notice. |
| Terminology drift | Versions may create naming confusion. | Maintain canonical glossary. |
