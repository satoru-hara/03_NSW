# HNS OS — Minimal Specification
**Human Neural Structure (HNS) — Minimal Operational System**

---

## 1. Purpose
HNS is a structural operating system for handling human and AI cognition, behavior, and relations without confusion.

Objectives:
- Eliminate cross-domain confusion  
- Maintain structural purity in decision-making and communication  
- Externalize and standardize the system for long-term inheritance  

---

## 2. Core Structure
HNS consists of **Layer × Category × Boundary**.

---

## 2.1 Layers (3-Layer Model)

### Layer 1: Cognition
- Perception  
- Evaluation  
- Intention  

### Layer 2: Behavior
- Choice  
- Execution  
- Maintenance  

### Layer 3: Relation
- Role  
- Expectation  
- Dependency  

---

## 2.2 Categories (9 Categories)

| Layer     | Category    | Definition                     |
|-----------|-------------|--------------------------------|
| Cognition | Perception  | What is being perceived        |
| Cognition | Evaluation  | How it is judged               |
| Cognition | Intention   | What is desired                |
| Behavior  | Choice      | What is chosen                 |
| Behavior  | Execution   | How it is carried out          |
| Behavior  | Maintenance | How it is sustained            |
| Relation  | Role        | What position is held          |
| Relation  | Expectation | What is expected               |
| Relation  | Dependency  | What it depends on             |

---

## 2.3 Boundary (Confusion-Prohibition Rules)

The following confusions are prohibited:
1. Intention ≠ Choice  
2. Individual ≠ Relation  
3. Evaluation ≠ Fact  
4. Experience ≠ Structure  
5. Personal values ≠ HNS  

Boundary violations must be detected, stated, and corrected.

---

## 3. Output Rules
All outputs using HNS must:
- Separate Layers clearly  
- Specify Categories explicitly  
- Identify Boundary violations  
- Assign the correct structural location (Layer/Category)  
- Provide structure without confusion  

---

## 4. Intervention Order
Interventions must follow this order:
1. Cognition  
2. Behavior  
3. Relation  

Reversing this order breaks structural integrity.

---

## 5. Minimal Foundation
HNS is fully operational with:
- 3 Layers  
- 9 Categories  
- Boundary rules  

This constitutes the minimal OS.

---

## 6. Standardization Path
1. Externalize the OS  
2. Formalize Boundary rules  
3. Fix output rules  
4. Expand to the 36-matrix (Layer × Category × Relation)  
5. Synchronize successors  
6. Transfer to a standardization body
