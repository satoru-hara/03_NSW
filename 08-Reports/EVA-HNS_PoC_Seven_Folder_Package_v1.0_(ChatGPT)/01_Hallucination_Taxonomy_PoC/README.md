# HNS Structural Hallucination Taxonomy PoC v1.0

**Classification of AI Failure Modes Using the HNS Five-Type Taxonomy**

Author: **Satoru Hara / Natural Structure Works (NSW)**  
Status: **Demonstration PoC / preliminary author-led verification**

## Purpose

Demonstrate that recurring AI-output failures can be classified using the HNS structural hallucination taxonomy.

---

## Main Demonstration Claim

> The HNS five-type taxonomy provides a usable classification vocabulary for structural AI-output failures.

## What This PoC Demonstrates

The HNS five-type taxonomy provides a usable classification vocabulary for structural AI-output failures.

---

## What This PoC Does Not Claim

This PoC does not claim that the five types exhaust all possible AI failures or replace factuality benchmarks.

This folder should be read as a demonstration package, not as independent certification.
