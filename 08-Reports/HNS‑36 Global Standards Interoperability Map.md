This document provides the interoperability mapping between the HNS-36
coordinate system (6 Human Natural Layers × 6 Abstract Cognitive
Categories) and the major global AI governance standards.

HNS-36 functions as a structural diagnostic layer that positions any
phenomenon at the intersection of causal origin (Layer) × explanatory
purpose (Category). This map demonstrates where HNS-36 structural
coordinates correspond to requirements in international AI standards.

---

## 1. HNS-36 Overview

### Human Natural Layers (Causal Structure)

| ID | Layer | Description |
|---|---|---|
| L1 | Physical | Physical and biological foundations |
| L2 | Perceptual | Perception, memory, internal processing |
| L3 | Internal | Inner states, emotion, cognitive load |
| L4 | Intentional | Purpose, decision, goal orientation |
| L5 | Relational | Communication, cooperation, social exchange |
| L6 | Societal | Institutional environments, systemic patterns |

### Abstract Cognitive Categories (Explanatory Axes)

| ID | Category | Description |
|---|---|---|
| C1 | Existence | Basic condition, structural state, presence |
| C2 | Perception | What is sensed, noticed, or received |
| C3 | Interpretation | What is understood, explained, or classified |
| C4 | Intention | What is aimed at, selected, or directed |
| C5 | Action | What is done, executed, or performed |
| C6 | Interaction | What is exchanged, connected, or coordinated |

## 5. Why This Mapping May Be Useful

HNS-36 coordinates can help organize AI governance discussions because:

- **Layers** define where a phenomenon originates (causal domain)
- **Categories** define how it is interpreted (explanatory axis)
- **Cells** define structural positions that can be referenced across standards

This makes HNS-36 a potential structural reference layer for aligning AI
system documentation with global regulatory frameworks.
