## Overview

This folder contains interactive Proof-of-Concept (PoC) demos for the  
**HNS-36 External Verification Architecture** — a framework for verifying AI outputs  
against a 6-layer × 6-category coordinate system of human cognition and social structure.

Each PoC is a standalone HTML file. No installation required.  
Files marked **[API]** require an Anthropic API key (`sk-ant-…`).
