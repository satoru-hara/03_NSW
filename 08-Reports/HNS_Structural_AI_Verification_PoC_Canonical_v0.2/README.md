# HNS Structural AI Verification PoC
Natural Structure Works (NSW)  
Author: Satoru Hara  
Location: Toyota, Aichi, Japan

This repository contains the Proof of Concept (PoC) for **HNS Structural AI Verification**, a deterministic and model-independent framework for evaluating the structural coherence of AI-generated reasoning.

The PoC demonstrates that reasoning can be externally verified and stabilized using the canonical **HNS-36** coordinate system.

---

## 1. Overview

The PoC provides:

- claim segmentation  
- HNS-36 coordinate mapping  
- structural violation detection  
- stability scoring  
- corrected output generation  
- JSON verification reports  

All components are deterministic and rule-based.

## 3. HNS-36 Reference

HNS-36 is a 6×6 structural matrix composed of:

Layers:
- L1 Physical  
- L2 Perceptual  
- L3 Internal  
- L4 Intentional  
- L5 Relational  
- L6 Societal  

Categories:
- C1 Existence  
- C2 Perception  
- C3 Interpretation  
- C4 Intention  
- C5 Action  
- C6 Interaction  

Each claim maps to exactly one coordinate.

## 7. Limitations

The PoC is not:
- a truth detector  
- a psychological model  
- a causal reasoning engine  
- a replacement for domain expertise  

It evaluates **structure**, not correctness.
