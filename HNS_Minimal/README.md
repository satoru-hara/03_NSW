# HNS Minimal — Overview

This directory contains the **minimal core of the Human Neural Structure (HNS) OS**.

---

## HNS Minimal includes:
- The essential 3-Layer × 3-Category structure  
- Boundary (confusion-prohibition rules)  
- Output rules  
- Intervention order  
- Standardization path  

This is the **pure OS**, without examples, applications, or extensions.

---

## Files

### **HNS_OS_Minimal.md**
The complete minimal specification of the HNS Operating System.  
This is the core document and the only required component for HNS to function as an OS.

## Purpose of This Directory
- Provide a clean, isolated location for the HNS OS  
- Prevent mixing OS with extensions or application-level content  
- Ensure clarity for new readers and contributors  
- Maintain structural purity for standardization
